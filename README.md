WinklerFoundationBeam

Web application for the analysis of a beam on a Winkler elastic foundation (finite element solution with the exact transcendental element stiffness matrix). It runs entirely in the browser as a single static page (index.html); no data leave the user's computer.

Live page (GitHub Pages): https://sdgee-lab.github.io/WinklerFoundationBeam/

Contents
index.html: the application (HTML and JavaScript, no dependencies).
docs/WinklerFoundationBeam_verification_TE7400.pdf: verification report against the worked example with analytical solutions of the course ΤΕ7400 - Πεδιλοδοκοί.
